## 2. 七条硬伤复核（逐条对应）

### 2.1 街格铺满 + 独立铺装 + 中轴御道

- 坊格按网格铺满城内，宫城/皇城占压的格子跳过；实测坊数见 3.2。街网为独立铺装层：纵街 / 横街用石板 `stoneB`，坊内地面为夯土 `soil`，色差拉开；中轴御道用深色石 `stoneDark`，宽度 = 街宽 × 2.1，自南门贯穿至宫城正门。
- 街宽 ∶ 坊边实测 0.062 ~ 0.070（约 1∶14 ~ 1∶16），落在锚点「坊边 558~700m 对街宽 35~65m，约 10~15∶1」区间附近；洛阳坊边折米 ≈ 554m，与「坊 500 余米见方」吻合。
- 坊块 LOD：四面坊墙 + 一片屋面体量 + 低模顶，不铺坊内十字街、不套院落装配器；网格必须铺满，不靠少放坊块省面。

### 2.3 紫禁城殿宇体量回落

- 外朝三殿 + 内廷三宫沿中轴前后排列；主殿面阔按城宽百分比生成：首殿 `W×0.07`，后续殿 `W×0.07×(1-k×0.16)` 递减，后宫 `W×0.055×(1-i×0.15)` 递减。
- 每殿带三层汉白玉台基（下层台明 + 中层 + 上层收分）+ 殿前石板广场；首殿两侧配殿体量递减（`0.4W × 0.6D`，低模顶）。
- 实测首殿殿身面阔 / 城宽：唐长安 6.7%、洛阳 6.7%、北京 6.7%、**紫禁城 6.6%**（真实太和殿 64 / 961 = 6.66%），落回个位百分比；不再出现三座金顶殿占内城三分之二。

### 2.5 城墙厚度、收分、雉堞与女墙

- 墙身三段：石脚 0~0.9 → 砖身 taper 自底宽收分到顶宽（带横向砖缝皮条线）→ 压顶条石 + 城墙顶面；外侧雉堞按 2.2 单位间距离散排布（堞宽 0.55，带望孔），不再是整圈锯齿贴图；内侧女墙 0.42 高保留。
- 底宽 ∶ 顶宽实测：唐长安 2.00 ∶ 1.00（=2∶1，配合墙高 4.0，即 4∶2∶1）；北京 3.40 ∶ 1.70（=2∶1）；紫禁城 1.37 ∶ 1.06 = 1.29，与真实 8.62 ∶ 6.66 = 1.29 一致。

### 2.6 马面：取舍说明与比值对表

- **冲突**：北京内城实测敌台 172 座、间距 70~100m；若按本工具缩比 20.67 m/单位把真实间距折进来，面数会到几百座，与 15 万三角预算冲突。
- **取舍**：不提高缩比（保持 footprint 与真实城宽对表一致），改用「**每面 N 座等距**」参数化（`bastionN`），间距 = 该面墙长 ÷ N，避让城门开口与转角角台；不追求真实 172 台的绝对数量。

| 洛阳 | 40 | 30.00 / 21.60 / 30.19 / 30.19 | 28.00 | 4.0 | **7.00** |

三座有马面的城比值 6.82 ~ 7.27，均落在 6~8 倍墙高区间。

### 2.7 长安正门五门道

- 唐长安 `gateCount=5`，五券洞沿中轴真并排；城台进深 `Dg = 墙底宽 + 2.6`，门洞深色内膛收在 `±(城台半深 - 0.35)` 留砖壳，并在正/背面各贴一道深色洞口板，券脸石与红板门贴外-face，五孔完整露出、不被城墙厚度吃掉。城门裁切图可数出 5 个并排券洞。

### 5.4 结构做法（装配器实测对应）

- **城墙三段收分**：石脚 → taper 砖身（底宽到顶宽，皮条线）→ 压顶条石 + 顶面；外侧雉堞离散排布带望孔，内侧女墙保留；四面闭合，转角设角台。
- **城门**：城台加深，多门道沿中轴真并排，券脸石 + 券脚 + 深色内膛 + 红板门；城楼复用分层楼阁/殿堂装配，侧门用低模屋顶。
- **马面**：每面 N 座等距、突出墙外，台上铺舍 + 低模橹顶；避让城门与转角。
- **角楼**：四角各一座，立角台上，小殿身 + 四坡低模屋顶，体量小于城门楼。
- **里坊**：四面坊墙 + 一片屋面体量 + 低模顶；不铺坊内街、不套院落装配器。
- **中轴宫殿群**：三层台基 → 殿身 → 高/低模屋面，殿前广场，首殿两侧配殿递减；外朝三殿在前、内廷三宫在后，整轴收在宫城/城垣内。
- **护城河**：四边投影条带闭合环濠 + 驳岸条石贴墙基 + 城门石桥；梯形城南北边宽不同。
