# 阶段 9 · 部件生成总表（表单 → 方式分配 → 按序重生成）

> 范围：50 个预设、1032 个 tag、2,373,932 三角面（320 档实测），归并为 221 个族、48 个受管部件。
> 目标：① 每件都能在 320 ppm（1 px≈3.1 mm）下站得住；② 同为「贴面/出皮」的部件不再抢同一个平面；③ 按本表顺序重生成。

## 0 三条纪律（本表的全部约束都落在这三句上）

1. **一件一主式**。同一个部件只许一个主生成方式，备选方式只在「主式在某档 LOD/某形制下不成立」时整件切换，不允许同一处在同一模型里混用两种方式——混用必出同面或穿插。
2. **一件一槽**。每件占据一个深度带 `SLOT[part] = {z0, z1}`（相对宿主外皮，单位 mm，正为出皮）。同一槽只放一件；相邻槽的**前脸**至少相差 2 mm，且相邻槽的带子必须**相交**（你咬我 3 mm、我咬你 4 mm），禁止端面齐平——齐平就是转视角时的那条闪线。
3. **顺序不可回头**。生成顺序固定：台基 → 柱网/柱础 → 墙身 → 勒脚/腰线 → 门窗 → 额枋/雀替/斗栱 → 屋面 → 平座/栏杆 → 装修（天花/碧纱橱/匾额/灯）→ 环境。后序件只能占「前序件已经占掉的体积之外」的槽，不许后序件回头咬前序件的主面。

## 2 生成方式分配表（主 / 备 / 槽位 / 320 档真实化）

方式代号：

- **M1 盒体** `mb.box/boxC`：轴对齐六面，用于方料、板、须弥座各层
- **M2 棱台** `mb.taper`：收分/斗欹/脊筒
- **M3 多棱柱** `mb.cyl(n, noCap)`：柱、竿、净瓶、望柱
- **M4 轮廓拉伸** `mb.prism`：塔身、拱券、月洞、山花、阙身
- **M5 车削** `mb.lathe`：宝顶、柱头、香炉、灯室
- **M6 网格壳** `P.wallWithHoles`：带洞墙，只出外皮+内皮+洞边
- **M7 参数曲面** `patch(u,v)` 举折 + `ribOffset` 瓦垄
- **M8 边缘带** 沿边参数扫掠（檐口/博风/压顶/脊）
- **M9 通长梁** `run/beamBetween`：额枋/寻杖/连檐/压顶
- **M10 模数组装** `P.dougong`：栌斗→泥道栱→华栱→昂→散斗→耍头
- **M11 门窗扇组** `doorAt/windowAt`：框+扇+纸+格心+裙板+五金
- **M12 栏杆串** `railing`：地栿→望柱→栏板→净瓶→寻杖→坐板
- **M13 贴面片** `quad`：纸、匾、影壁、铺装
- **M14 道具组** 石狮/石灯/香案/榻/花池（组合体）
- **M15 母题实例化** 同形复用（树/花/瓦当/斗栱），拓扑只造一次

**由槽位反推的三条硬规则**（写进 `cli/coplanar.js` 的门槛判据）：

1. 同族内两个子件的 `z1` 相等 → 违规（例：裙板 52 vs 裙板线 58 已改前是 40/40）。

3. 两个子件的带子在平面内相交且 `z` 带也重叠超过 70% → 违规（穿模）。

### 7.12 批 6（植被母题实例化与叶片厚度）

植被是整套预设里**最大的隐形共面库**，比批 4 的斗拱还大一个量级，而且藏了六轮都没被发现，原因很直接：`coplanar` 默认只报单对 ≥0.02 m²，而每片叶子的一对共面只有 0.004 m²。

按 0.001 阈值扫，批 6 之前的数字：

| 预设 | 叶类共面对 | 面积 |
|---|---|---|
| wujin | 10,143 | **44.73 m²** |
| siheyuan | 13,313 | **64.44 m²**（竹 42.44 + 银杏 22.00） |

病根只有一条：`leafBlade` 把同一片叶**正反各画一遍**（`mb.quad(A,B,D,C)` 紧跟 `mb.quad(C,D,B,A)`，三角同理），两组三角面位置完全相同 —— 这是一对完美的 z-fighting。而渲染器本来就是“法线朝相机翻正、绕向无意义”，单面早就能双面可见，背面那一遍纯属自找。

**三项改动：**

1. **母题实例化**：新增 `LEAF_MOTIF` —— 五点单位坐标（u 沿叶长 0→1、v 横宽 ±1、w 下垂 0→1），根边收 0.3、中腰最宽、叶尖收点。`leafBlade` 变成“算一次三角函数 + 五点线性映射”，竹/柳/银杏/杂树共用同一母题，不再各自重算四角。
2. **叶片厚度**：320 档（`det≥3`）沿中肋抬 `min(8, max(4, hw×0.12))` mm，把平面叶折成 V 形断面（左右两半各一张四边面 + 两片叶尖三角）。平片时代叶子斜对镜头就是一条零宽度的线；折过之后任何角度都有 3–5 px 的实体厚度。低档不开折，仍是单面平片，交互预览不多花面。
3. **去掉正反重复面**：叶、花瓣（`blossom5`）、芭蕉叶三处一起改。

- **实测（ppm=320）**：叶类共面 wujin **44.73 → 0**、siheyuan **64.44 → 0**（全 0 对）。三角面 wujin 214,422 → **210,702**、siheyuan 161,298 → **158,578**、dian 59,822 → **58,142**；植被占比 21.7% → 20.3%。梅·瓣 7,440 → 3,720（少了背面那一遍）。
- 整模（0.02 阈值）：qing 0.31、siheyuan 0.47、wujin 0.71、tang 0.68、dian 1.03、廊院 2.11、水榭 0.45 m² —— 与批 5 持平；叶类共面不计入阈值排行，故整模数字不动，但实际闪面消失了 44–64 m²。
- 64 套审计 error 0 / warn 0；出图 `out/阶段9/p6_siheyuan.png`（240 档 7,763×5,482）→ `p6_siheyuan_small.png`（竹、梅、银杏三种叶型与瓦垄凹曲同框）。
