## 操作要点 / 坑
- Windows + pwsh；Bash 不可用。`Set-Content -Raw` 后**多行 `\n` 锚点匹配不到 CRLF**——批量替换只用**单行锚点**，改完立刻 `node cli/preset-audit.js` + 全 preset `GF.build` 烟雾测试。
- 曾两次事故：踏跺改错方向（2.28→3.73，已回退）；`rr` 误插进 `platform`（`a` 未定义，已按行号删除）。教训：不明白变量语义就不改。
- 大图（>5 MiB）`Read` 会失败、GDI 会把透明底看成黑：出图前必须 `Graphics.Clear(White)` 压平 + 缩到 ~860 px。
- 已知未表态项（勿擅改）：`gf-core` 调色板 `marble` 非法 hex；`PREVIEW_MAX_PIXELS` 是否下调；塔檐"翘角"小段梁是否改形。
