# 古建形制基准表

> 用途：本工程 `E:\_GamesTool\_开发工具\guofeng-pixel-building-studio` 后续五个改造阶段（① 民居演变谱系 ② 塔与楼阁 ③ 城分页 ④ 布局类 ⑤ 寺院山门大殿结构修正）的"可对表"依据。
> 读法：每一行给出平面形制、竖向做法、可量化比例、以及落到 recipe 哪个字段 / 哪个形制开关。缺数字或只有形容词的行视为不合格。

## 口径与来源纪律（硬性）

1. **recipe 内是抽象尺度**：表内米数仅在有可靠出处（维基百科、文物局 / 学术论文 / 官方介绍）时标注并附 URL；工具出图按比例对参数，不要求还原真实米数。
2. **无出处的数值一律写"常识性形制，非实测"**，并给出形制理由；只给比例区间（如收分 0.85~0.92 / 层），不编造精确假数。
3. **B 站页与 ArtStation 页只能取标题 / 简介 / 结构关键词**，拿不到逐帧内容；任何尺寸都不写成"来自视频 / 视频里是 xx 米"。ArtStation 四个参考页本次实测均不可抓取（站点不支持访问），表内仅按给定标题与关键词登记。
4. 字段名对齐 `js/gf-presets.js` 的 `DEF`（recipe 归一化默认值）；表中"落地建议"出现的字段均为现有字段，标注"待补"的为改造阶段需要新增的字段 / 构件。

## 五、五阶段改造要点

### 阶段① 民居演变谱系

1. **补年代档开关**：`house` 增加穴居 ∕ 汉 ∕ 唐 ∕ 宋 ∕ 明清江南 ∕ 徽州六档，每档绑定 `eave`∕`slope`∕`upturn`∕`dougong`∕`roofType`∕`wallMat` 默认区间（比例见第一章）。
2. **穴居档**：矮台基、锥顶 ∕ 四坡草顶、`soil` 墙、无斗拱；待补半地穴下沉坑体构件（`baseH` 负值或坑体围合）。
3. **谱系联动默认值**：唐→宋→明清，`dgScale` 由大到小、`eave` 由深到浅、`slope` 由缓到陡；起翘 `upturn` 随年代与地域递增。
4. **地域绑定**：徽州 `horseWall=true`；江南天井与 `env.pond` 绑定；窗格 `winPattern` 随档位切换（straight ∕ lantern ∕ ice）。

### 阶段② 塔与楼阁

1. **塔逐层数组**：`pagoda` 补齐 `sides=8`、外观 `tiers`、`eaveList`∕`shrinkList`∕`dgList`；默认收分 0.88~0.92 ∕ 层；`pingzuo` 逐层、`fujie` 底层周匝。
2. **楼阁多层檐与抱厦**：`ge` 支持明三暗五 ∕ 多层腰檐（`tiers` = 滴水数）；待补抱厦突出体量；`roofType='cross'` 对应十字歇山。
3. **塔刹比例**：`finial` 高度与塔身比例可调（参照木塔刹约 10 m ∕ 通高 67.31 m、雷峰塔刹 16.10 m ∕ 通高 71.679 m）。
4. **概念参考回落**：ArtStation 四稿只做轮廓参考，参数回落到本章实测档 ∕ 常识档，不设虚构米数。

### 阶段③ 城分页

1. **新增 `city` 类型**：城墙（`wallH`∕底宽∕顶宽，按 4∶2∶1）、城门（`gateW`∕`gateH`∕门道数）、马面（间距 70~100 m 档）、角楼、城濠（`moat.width`∕`depth`）。
2. **街网 ∕ 里坊**：`blockW`∕`blockD`∕`streetW` 字段；坊尺寸与街宽参照唐长安 ∕ 洛阳实测区间。
3. **比例锚点**：河宽 ∕ 墙高——故宫 ≈ 5.2、北京内城 ≈ 2~5；马面间距取 70~100 m；城墙高 ∕ 底宽 ∕ 顶宽 = 4∶2∶1。
4. **宫城轴列**：复用 `hall`∕`tai`∕`ge` 装配中轴宫殿群；台基三层、配殿体量递减。

### 阶段④ 布局类

1. **院落轴列生成器**：寺观（山门→前殿→主殿→后殿 ∕ 阁）、五进四合院（倒座→垂花门→厢正房→后罩）、府邸 + 花园复合，按 4.1 序列装配。
2. **舫三段体量**：`fang` 前高 ∕ 中低 ∕ 尾二层；前后歇山、中部两披；船头敞棚 + 平桥接岸。
3. **`courtStyle` 扩充**：现有 siheyuan ∕ garden ∕ temple 三档，待补廊院式、城坊式两种枚举。
4. **环境预设**：池 ∕ 山 ∕ 树 ∕ 石 ∕ 幡 ∕ 道具按五种布局范式绑定默认 `env`。

### 阶段⑤ 寺院山门大殿结构修正

1. **山门与天王殿分离**：山门（一门三洞）不得与天王殿合一；钟鼓楼分列山门两侧。
2. **主殿体量等级**：大雄宝殿为全寺最高最大，配殿进深 ∕ 开间递减；月台 `pedestal` + `railing`。
3. **屋面与斗拱等级**：主殿歇山 ∕ 庑殿，斗拱等级高于配殿；`dgScale`∕`dgStyle` 按殿位分层。
4. **轴线抬高**：沿轴线院落逐级抬高（`baseH` 递进），形成前低后高、层层递进的轮廓。
