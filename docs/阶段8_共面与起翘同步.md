# 阶段 8 · 剩余共面闪烁与檐角起翘同步

对应反馈两张截图：

1. 图 1（五进四合院，剖切视图 320 档）红框圈住的“红檐柱 + 灰墙”竖条 —— 柱身上那几个红色小半圆/钩子，转视角会闪。
2. 图 2（长殿，悬山、出檐 1.28、举折 0.50、起翘 0.70）红框圈住的两个檐角 —— 屋面翘了，山面一侧不翘，即“连接处只翘半边”。

本轮共 5 处改动，都在几何层，未动渲染器。

## 一、图 1：`cyl` 顶底扇面从墙缝里露头

`js/gf-core.js: cyl()` 给每根柱子都铺了顶、底两片三角扇。柱轴与墙中轴只差 0.1 m（`00-common.js body()`：柱心 `z1-0.2`、墙心 `z1-0.1`、墙厚 0.22），小尺寸建筑 r=0.17、墙皮与柱皮只剩 0.8 cm —— 于是扇面必然有一部分越过墙面探出来，屏幕上就是柱身上那几块亮红色的半圆/钩子；相机一动，探出的部分在两个面之间来回翻，就是闪。

修法：檐柱不出顶底扇面（`cyl(..., rot, noCap)`，`body()` 传 `true`）。顶上本来压着额枋/斗栱、底上埋进柱础，两片扇面在任何正常视角都看不见。顺带每柱省 16 个三角面。

- 修前：`01_图1位置_修前.png`（柱身中部有明显的亮红扇面边）
- 修后：`02_图1位置_修后.png`

## 二、图 1 的主因：整圈院墙被砌了两遍

`30-courtyard.js: buildCourtyard()` 先用 `P.courtWall()` 砌一圈外围墙（tag `院墙`），再分派到 `courtyardWujin / temple5 / daoguan / langyuan / jiafu`；这五种布局各自又砌一遍自己的外围墙（wujin 是 `院墙·前/后/左/右` 四个盒子，其余是第二次 `courtWall`）。两圈墙同为 0.3 m 厚、同一条中线，严格同面 —— 仅 wujin 一圈就有 437 m² 的墙身同面（右 119.7 + 左 119.7 + 后 60.3 + 前 44.6 + 压顶），也是全模型 1219 m² 共面重叠里最大的一块；屏幕空间 14408 个争用像素中，`院墙 × 院墙·前/后` 两对就占 15010 像素次。

顺带一个实打实的建模错误：wujin 的宅门在 `gateX = CW/4`（东南隅），而 `courtWall` 的洞口开在正中 —— 中间那圈墙把宅门整个埋住了，修前渲染里根本看不到门。

修法：

- `30-courtyard.js`：进数/轴线类（`temple5 / daoguan / wujin / langyuan / jiafu`）不再砌这圈外圈墙，各自的外墙就是唯一一圈。
- `gf-parts.js: courtWall()` 新增 `body:false`：只出压顶与瓦脊、不出墙身。wujin 用它补出四面压顶/脊（原来只有前墙有一条压顶），并删掉自己那条重复的 `院墙·压顶`。

- 修前：`07_整院_修前.png`（前墙叠两道，宅门不见）
- 修后：`03`/`08_整院_修后.png`（前墙一道，东南隅宅门露出）

## 三、瓦条：上下两道贴成一张同面孔

`addRidge()` 里两道瓦条 `dy = 0.06 / 0.16`，前一条顶面 `rh*0.06+0.022` 恰好等于后一条底面 `rh*0.16`（rh=0.22 时都是 +0.0352），两条细线严丝合缝贴成一张面，整条脊（四合院 18.07 m²）一转视角就闪一道。修法：后一条底面压进去 5 mm。

## 四、图 2：山花与博风没跟着起翘抬

`js/gf-roof.js: gableRoof()` 的瓦面在檐角抬 `up*cornerLift(u)*(1-v)^1.5`，但山花三角与博风板仍按平标高 `yb` 建：

```
檐口(±xe, ±ze) 瓦面 y = 8.700
山花三角角点     y = 8.000     → 缺口 0.70 m
博风             y 7.924..14.076（一条直线，落在翘起的瓦面之下）
```

于是转角处瓦面翘起来了、山面和博风还压在老标高上，只剩“一边翘”。

修法：山花轮廓改为直接取**抬高后的瓦面边线**（`slope(±1)(u=0/1, v)` 采样 6 段），以脊点为心做三角扇；檐角翘起后檐口与墙顶之间那条 0.7 m 宽带给一块矩形补齐（不再把底角算进扇心，避免自交）；博风板沿同一条边线串成短梁，起翘处逐段跟着抬。

`rollRoof()`（卷棚）同病：山花首末两点写死在 `yb+0`，改成 `yb+up`。

修后实测（悬山 W31 D14.8 起翘 0.70）：

| 部位 | 修前檐角 y | 修后檐角 y |
| --- | --- | --- |
| 瓦面（前/后坡） | 8.700 | 8.700 |
| 山花 | 8.000 | **8.700** |
| 博风 | 7.924（直线） | 8.603..14.065（沿边线） |

- 修前：`03_悬山檐角_修前.png`（博风是一条直棍，从翘起的檐角底下直接戳出去）、`05_悬山山面正视_修前.png`
- 修后：`04_悬山檐角_修后.png`（博风与山花一起翘，连接处闭合）、`06_悬山山面正视_修后.png`
